# A 38-dimensional lattice packing of center density \(8\sqrt2\)

This lattice has squared minimum 8 and Gram determinant \(2^{31}\). Its exact center density \(8\sqrt2\) equals the preceding periodic 38D construction and improves the preceding listed **lattice-only** bound (center density about 9.4806808308). This is a lattice construction, not an unrestricted upper bound.

Use as horizontal lattice the verified five-E7 lattice \(L_{35}\) of squared minimum 8 and covolume \(2^{31/2}\). Its binary phase labels \((x,e)\) in each block are encoded by the included E7 Cartan/field identification. The three syndrome checks are \(s_0=\sum x_i,\ s_1=\sum \alpha_i x_i,\ e=\sum e_i\), packed as \(s_0+64s_1+4096e\). For any syndrome \(s=(a,b,e)\), let \(\operatorname{rep}(s)\in E_7^5\) use phases \((a+b,e),(b,0),0,0,0\) in the five sites, taking the literal binary E7 coefficients of each phase. This works because \(\alpha_0=0,\alpha_1=1\).

Let \(r\) be the E7 radical representative of binary coefficient mask 82, and let \(\beta\in E_7^5\) be the five binary coefficient rows packed in two-bit digits as \(272,1360,1,1089,0\). Set the new horizontal generators to
\[
A_h=(r/2)^5+\operatorname{rep}(439),\quad
B_h=\beta/2+\operatorname{rep}(291),\quad
C_h=\beta/2+\operatorname{rep}(684).
\]
Their vertical partners in Euclidean 3-space are
\[
A_v=(1/2,1/2,0),\quad B_v=(1,0,1),\quad C_v=(0,1,1).
\]
The lattice is generated by the horizontal \(L_{35}\) and these three paired generators. Its vertical basis determinant has absolute value 1, so the block triangular basis has covolume \(2^{31/2}\). The classes of \(A_h,B_h,C_h\) modulo \(L_{35}\) are killed by 4,2,2 respectively. Each corresponding vertical multiple lies in \(2D_3\), and the three vertical multiples generate \(2D_3\).

## Exact minimum proof

For each of the 16 classes \((k,l,m)\in\mathbb Z/4\oplus(\mathbb Z/2)^2\), compute independently the horizontal minimum over \(kA_h+lB_h+mC_h+L_{35}\) and the vertical minimum over \(kA_v+lB_v+mC_v+2D_3\). This separation is valid since the entire orthogonal product \(L_{35}\oplus 2D_3\) is a period. The 16 exact component costs, scaled by 4, are in certificate38.json. Every nonzero class has cost sum at least 32. The zero class has squared minimum 8, attained in the horizontal lattice. Therefore the entire packing has squared minimum 8.

The local E7 table consists of shortest squared lengths in every coefficient residue modulo 4. The exact integer LDL ellipsoid enumeration fills all residues using vectors of squared length at most 40; the largest representative minimum is 24. For horizontal generator combination \(X/2\), the cost for phase \(v\) on a block is the mod-4 local squared minimum at \(X-2v\), giving four times the physical cost. A five-step exact min-plus convolution on the binary syndromes gives the horizontal cost at syndrome zero. For the vertical part, compute minima among doubled integer representatives \(z+4n\), with \(n\in D_3\); the small bounded box in the verifier contains every possibility of squared cost at most 32.

## Replay

Run python verify35.py (horizontal exact minimum), python verify38.py (the 16 exact residues), and python basis.py (exact determinant). Dependencies: Python 3, NumPy, SymPy and a C++17 compiler. basis38.json stores the 38-by-38 coefficient basis multiplied by 2 and the Gram matrix multiplied by 4. The underlying coordinates use five copies of the E7 Cartan basis followed by three Euclidean coordinate axes. JSON regeneration uses --write.
