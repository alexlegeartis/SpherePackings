# A strict 11D sphere-packing improvement by phase slips

This is an explicit periodic nonlattice packing beating the historical `P11a` centre density `9/256` from [Leech–Sloane, 1970](https://neilsloane.com/doc/Me7.pdf) and [their explicit binary construction, 1971, §2.6](https://neilsloane.com/doc/Me14.pdf). The live project and attributed reference use that same unrestricted comparison. The shorter-period witness in the last section gives a certified relative gain **strictly greater than `1.6×10^−14`**, strict by exact arithmetic but negligible in ordinary display. The mechanism is nonlocal and permits a huge superperiod. It does not improve the lattice-only bound.

The fixed squared-minimum-4 exclusion in `README.md` does not contradict this construction: here the squared diameter is `mu=4−2^−52`, and the vacancy array is packed at a different longitudinal density. To verify the constructive theorem only, the *sole* datum needed about the 71-point core beyond its own separation is that each core residue has Hamming distance at least 5 from `u=(1,1,…,1)`. That datum follows by generating the listed Witt-derived code; the 11D covering proof is not used.

## The packing, in (transverse 10D, axial 1D) coordinates

Keep exactly the 71 complete cosets of `2 Z^11` called the core in `README.md`, in the same scale. Take the axial coordinate to be coordinate 10; take one transverse unit vector `e` in coordinate 0. Write `u_tr=(1,…,1)` in the ten transverse coordinates and set

```
h = 2^(−13), eps = h^4 = 2^(−52), mu = 4−eps.
```

Produce the ordered partition `0=phi_0<...<phi_N=2` as follows. Subdivide `[0,h]` into steps of length `eps/4`. Subdivide each dyadic interval `[a,2a]`, `a=h,2h,...,1/2`, into steps of length `a^4/16`. Reflect these partition points through 1 to fill `[1,2]`; duplicate endpoints are taken once. All segment counts are integers: `4/h^3` in the first segment and `16/a^3` in each of the others. Thus

```
N = (312·2^39 − 256)/7 = 24,503,401,990,400,       N is even.
P = 2(N−1) = 49,006,803,980,798.
```

For `0≤l<N` put `s_l=min(phi_l,2−phi_l)`, `t_l=s_l²/4`, `z_l=2l−phi_l`, and add the complete transverse layer

```
 (u_tr + (−1)^l t_l e + 2 Z^10, z_l).
```

Repeat these `N` layers with axial period `P`. Indeed `z_N=2N−2=z_0+P` and `t_N=t_0=0`; the next partition cycle has the same signs because `N` is even. All centre coordinates are rational, generated by only 28 blocks (the two reflected halves each contain 14 blocks); computing or storing trillions of explicit points is not necessary. In particular a direct formula for the motif point of any given index is obtained by looking up its interval, multiplying the within-interval index by the rational step length, and then applying the displayed layer formula.

## Exact distance proof

**Core–core.** The binary code has Hamming minimum 4, and each period `2 Z^11` has squared minimum 4. Thus all core–core distances have square at least 4.

**Core–new.** For a layer with phase `phi` the unshifted transverse point `(u_tr,z_l)` has distance `s=min(phi,2−phi)` from an even axial integer; equivalently its axial distance to the nearest odd integer is `1−s`. At `u` the squared torus distance to any core residue is its Hamming distance, at least 5. Changing only the axial coordinate from odd 1 to this phase reduces the squared distance to a given codeword by at most `1−s²` (the worst case is a residue with even axial coordinate). So its unshifted squared distance to the entire core is at least `4+s²`. On a circumference-two coordinate circle the squared distance to a fixed bit is 2-Lipschitz: both distances lie in `[0,1]`, and their absolute difference is at most the size of the displacement. The transverse move of magnitude `t=s²/4` reduces squared distance by at most `2t`, leaving `4+s²/2≥4>mu`. This applies uniformly to every core translate and axial period.

**New–new.** Each layer has in-layer squared minimum 4. Adjacent layers with phase increment `d=phi_{l+1}−phi_l` have positive axial gap `2−d`. Their shortest transverse displacement has norm `t_l+t_{l+1}`: the two offsets have opposite signs and the sum is at most `1/2`, so the wrap through a neighbouring translate cannot lower it. For any increment in an interval where `s_l,s_{l+1}≥a`, we have `t_l+t_{l+1}≥a²/2` and `4d=a^4/4`. The squared separation is therefore at least

```
(2−d)^2 + (t_l+t_{l+1})^2 ≥ 4−4d+d²+a^4/4 ≥ 4.
```

For the first and last small intervals, `d=eps/4`, so the axial square alone is `4−eps+d²>mu`. For any nonadjacent layers in the bi-infinite order, their axial separation is at least twice the minimum axial gap and hence greater than 2 (`d≤1/256` everywhere). These cases are exhaustive and include the junction across the period. Consequently the full packing has squared minimum at least `mu`.

## Strict density improvement, exact comparison

The supercell has volume `2^11 (N−1)` and distinct centre count `71(N−1)+N=72(N−1)+1`. At radius `sqrt(mu)/2` its centre density equals

```
 delta = (72 + 1/(N−1)) (1−2^(-54))^(11/2) / 2^11.
```

This is a certified achievable density, whether or not the true minimum of this same set is slightly larger. To compare exactly, set `F=72(N−1)`. The density ratio satisfies the Bernoulli inequality

```
 delta / (9/256) ≥ (1+1/F)(1−11 eps/8)
 =1 + [8·2^52−11(F+1)]/[8·2^52·F].
```

The rational relative improvement on the last line is exactly

```
16622102642567949 / 63563622954203754089284531912704
 > 26 / 10^17 > 0.
```

The packing is not a lattice: at the axial coordinates with nonintegral `phi_l` it contains one transverse residue from a complete `2 Z^10` layer, whereas at even axial coordinates the core contains more than one such residue. A lattice translated to contain the origin has the same cardinality in each nonempty transverse fibre modulo any common transverse period, because all its fibres of a homomorphism are cosets of its kernel. Here the cardinalities differ. More generally the exponent explaining the gain is `N=O(h^(−3))` versus radius loss `eps=O(h^4)`: slow axial slips arise only around pinches, and opposite small transverse motions absorb the axial compression away from them. No numerical optimization or floating-point margin is used.

## Stronger version with the same proof

Use `h=2^(-11)`, `eps=2^(-44)`, `t_l=s_l²/2` and dyadic increments `d=a^4/4` (the two tiny intervals still use `eps/4`). The condition `2t≤s²` still holds, so core–new separation is at least 4. The opposite transverse offsets sum to at most 1, not `1/2`; this is still a shortest difference modulo `2 Z`. The adjacent clearance proof is the same, using `t_l+t_(l+1)≥a²` and `4d=a^4`. Finally `d≤1/64`, so all nonadjacent axial differences still exceed 2. There are 24 partition blocks, and

```
N = (120·2^33 − 64)/7 = 147,256,021,568,
P = 2(N−1) = 294,512,043,134,
delta = (72 + 1/(N−1)) (1−2^(-46))^(11/2) / 2^11.
```

The exact Bernoulli relative improvement is now at least

```
24110719274253 / 1492159868678706575569846272 > 16 / 10^15.
```
