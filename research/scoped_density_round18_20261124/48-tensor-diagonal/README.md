# 48D zero-sum E8: all two-exceptional metrics fall short

**Theorem (scoped).** Let
`L = {(x_0,...,x_6) in E8^7 : sum x_i=0}/sqrt(2)`.
Put squared metric weights `(a,b,1,1,1,1,1)` on the seven slots, and allow **any** union of cosets of `2L` in `L`. Whenever the zero-sum metric is positive definite, the center density is at most **38,246,144/2401 (about 15,929.26)**, strictly below the extremal-48D level `(3/2)^24 = 16834.112196...`. This includes both exceptionally heavy slots, two light slots, and negative ambient weights up to the positive-definiteness boundary. It does not cover other periods, three or more exceptional weights, nondiagonal slot metrics, or arbitrary 48D lattice or periodic packings. The number 38,246,144/2401 (about 15,929.26) is a uniform upper bound for this family, not a claimed optimum.

Run `python3 verify.py` (Python stdlib and g++ with C++20, little-endian host). It regenerates the finite geometry and integer Fourier matrices, and checks every dual inequality with exact rational arithmetic. There is no solver or network in the replay. SciPy LP was used only to propose the stored nonnegative integer multipliers. The uniform six-slot dual is reused from the previous round and independently replayed.

## Geometry and normalization

By swapping the exceptional labels assume `a<=b`. The opposite-slot vector implies `b>0`; eliminating slot a gives the scalar matrix `diag(b,1,1,1,1,1)+aJ`. The rank-one update shows positive definiteness is equivalent to `D=a+b+5ab>0`, since b is positive. In particular a is greater than `-1/5`, and it is greater than `-1/6` if `b<=1`. The covolume of the period `2L` is `2^24 D^4` because E8 is unimodular and each scalar block is repeated eight times. If `g` is the packing's squared minimum and `N` its distinct phases, center density is `N (g/8)^24 / D^4`. The trivial cap is `N<=2^48`.

Opposite equal E8 roots in two ordinary slots give a period contact of square 8. In the two exceptional slots they give `4(a+b)`. Using multiples `(-(n+5r),n,r,r,r,r,r)` of one E8 root in the period gives square `4[a(n+5r)^2+bn^2+5r^2]`. This form on `(n,r)` has determinant `5D` before multiplication by 4. The planar Hermite inequality gives a nonzero contact of square at most `4 sqrt(20D/3)`: after Gauss reduction the angle has sine at least `sqrt(3)/2`, and the second length is at least the first. Thus all `D<=389/2000` have density at most `(20/3)^12 (389/2000)^8 < 15929` even with the trivial phase cap. This handles the entire positive-definiteness boundary without singular numerical sampling.

## Fourier fibre certificates

Let `V=E8/2E8`, the split binary quadratic space of dimension 8 with `q(x)=|x|^2/2 mod 2`. The quotient `L/2L` is exactly the set of binary zero-sum tuples: for any tuple of classes summing to zero, the sum of arbitrary lifts is in `2E8` and can be subtracted from one lift. Fix all but `k+1` labels, leaving at most `256^(6-k)` fibres. Each fibre difference lies in a copy of `V^k` with one dependent slot. The sizes used here are `k=2,3,4`; among the changing slots 0, 1 or 2 may be exceptional. If only one exceptional slot changes it is a, and b is fixed.

By Witt extension, diagonal binary orthogonal-group orbits are classified by the kernel of the label map and the quadratic form on its image. The verifier validates the E8 root-class dictionary and lifts of the whole orthogonal group through reflections. Permuting ordinary changing slots is also an isometry. For each difference orbit, the generator enumerates literal lifts by forcing one slot to minus the sum of shortest representatives in the others. It records affine witness lengths `h+a*l+b*m` using integer norm scores in doubled E8 coordinates, with the zero-sum carrier's factor `1/sqrt(2)`. For negative a, one keeps the **largest** forced length in slot a and smallest in the other slots. The nonnegative chart uses smallest in every slot. Discarding witnesses in either chart can only weaken the proof; it is not necessary for the generator to find the closest lift.

For column orbit j of size `N_j` and a representative character in row orbit i, write `W_ij` for its sum over column j. These integers are obtained by summing over the four hyperbolic coordinate pairs with an inverse Walsh transform and then subtracting the counts of larger kernels. For one binary pair the basic transform is
`sum_{x,y} (-1)^(x^T M y+A*y+B*x)=2^k sum_{x:Mx=A}(-1)^(B*x)`.
The code difference distribution has nonnegative Fourier coefficients (squared moduli). If nonnegative integer multipliers `v_i` have `z=min_j(-sum_i v_i W_ij / N_j)>0` over the allowed nonzero columns, this gives a fibre cap `floor(1+sum_i v_i/z)`. Apply this to the orbit-averaged code, so the argument requires **no** symmetry or additivity of the actual set of phases. If no nonzero columns survive, the cap is 1.

## Covering the continuum

The stored trees cover the closed parameter rectangles/intervals by bisection. In each tile use the determinant lower bound `D0`, and evaluate all literal witness lengths at the upper-right endpoint: every coefficient in each witness length is nonnegative. The minimum of those endpoint lengths in an orbit is therefore an upper bound for that orbit's shortest lift throughout the tile. Adjacent endpoint lengths partition the positive `g` axis into bands `lo < g <= hi`. For such a band, any column with witness upper bound at most `lo` is forbidden even at the tile boundary; equality to `lo` is treated in the preceding band. A verified phase count gives the density bound `N (hi/8)^24/D0^4`. All operations are rational.

* For `0<b<=1`, split a at zero, use the rectangular tiles of `[-1/6,0] x [0,1]` and `[0,1]^2`, and discard tiles outside `a<=b` or with all `D<=389/2000`. Both determinant partial derivatives are positive on these rectangles. Limit `g` by the displayed period witnesses at the upper-right endpoint, and for these tiles cover `g<=7`.
* For `a<=1<=b`, fix b in all fibres, bound `D` below by `1+6a` (or the common small-D cutoff), and bound g by `min(7,4(1+a),20(1+5a))`. The last term uses period multiples `(-5,0,1,1,1,1,1)`. Treat `-1/5<a<=0` and `0<=a<=1` separately, including negative a below the old one-exceptional boundary.
* For `1<=a<=b`, fix b, use `D>=2a+5a^2`, and cover `g<=min(8,7a)` when `1<=a<=2`. For `a>=2` fix both exceptional labels, bound `D>=24` and cover all `g<=8`. The verification inputs use b=0 for these last charts solely because the witness lengths have zero coefficient of b; it is not a metric assumption.

The remaining high windows use the exact uniform six-slot cap of 149,399 per fibre above squared minimum 7; with just one fixed label this gives `B=38,246,144` phases. If `a<=b<=1`, fix a, so the six weights are all at most 1. Literal uniform witnesses remain valid, including if necessary under smaller weights. Set `t=a+b`; for `g>7`, `t>7/4`, `g<=4t` and `D>=6t-5` since `ab>=t-1`. The factor `(t/2)^24/(6t-5)^4` increases to `1/7^4` at t=2 by logarithmic differentiation. If `a<=1<=b` and `g>7`, fix b, so the six weights are again at most 1. Now `g<=4(1+a)` forces `a>3/4`, and the same calculation with `t=1+a` applies. If `1<=a<=b` and `g>7a`, fix b and multiply all uniform witness lengths by at most a; use `g<=8` and `D>=7`. Each high-window cap is at most `B/7^4 = 38,246,144/2401`.

The theorem adds a second independent weight parameter to the previous one-exceptional exclusion. It is useful for deciding whether to search more complicated motifs on this same carrier: improving 48D through these squared metrics requires changing the period or leaving the two-exceptional family, not a larger phase search within it.
