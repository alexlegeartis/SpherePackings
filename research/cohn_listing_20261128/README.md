# Cohn sphere-packing table check, 28 November 2026

[Both live tables](https://cohn.mit.edu/sphere-packing/?v=20261128) were fetched on 28 November Moscow time (27 November UTC). This [normalized snapshot](snapshot.json) retains all printed values and references for dimensions 1–48 in both tables; older snapshots are preserved. The lower-bound and upper-bound source attribution follows each row and does not imply independent re-verification.

The only material difference between the unrestricted lower-bound catalog and the live 1–48D values was **11D**. [Cohn, ref. 9](https://cohn.mit.edu/sphere-packing/#9) records the alternating Witt slab packing, with 577 points, squared minimum 4 and period volume 16384; see [the MIT coordinates, entry `dimension_11.2`](https://dspace.mit.edu/server/api/core/bitstreams/f62f3534-129f-4388-acf9-db34bf63bfbf/content). He credits Kravatskiy's earlier phase-slip construction; the higher density is his. This is nonlattice. The printed 1–48D lattice **lower** values agree with the project's catalog at table precision. In the table of **lattice upper** bounds, 44D is attributed to [Zubrilina, ref. 37](https://cohn.mit.edu/sphere-packing/#37).
