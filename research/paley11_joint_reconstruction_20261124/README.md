# 11D packing ties: coordinated reconstruction and free slides

These literal periodic packings tie the known 11D center density 9/256. **They are not new density records.** Verify with `python3 -B verify_slide.py` (standard library only).

- `atlas-tie1.txt`: 288 sites on ((2D_4)^2\times 2\mathbb Z^3), primitive covolume 8192. This configuration came from a joint search over several Paley-derived backbones and donor banks, changing 24 sites relative to the input primitive 288-site motif. It has 287 noninteger squared wrapped pair distances. The input `trial-1-288.txt` has only integer squared distances between any two centers, even before wrap minimization, because odd doubled coordinates occur only in entire four-coordinate head blocks and periods preserve all doubled residues modulo 4. Thus this atlas witness is not congruent to the input.
- `slide20-288-k257.txt`: after replacing 20 of the original 288 sites, four sites still slide freely and simultaneously, one tail coordinate each. The file gives an explicit off-grid primitive member, with physical shifts (j/257), (j=1,2,3,4). The zero-based free axes are in `slide20-axes.txt`. For any pair involving a slider, removing the squared contributions of its free axes (one or two, counting a shared axis once) leaves squared wrapped distance at least 4. Consequently each free axis ranges over the full period-2 circle, independently. The particular off-grid realization is primitive and contains noninteger pair distances.
- `atlas-tie0.txt`: an additional 144-site tie on (2D_4\times2\mathbb Z^7), primitive covolume 4096.

A literal coordinate is twice physical length, except in `slide20-288-k257.txt` where it is 514 times physical length. The verifier checks every wrapped pair via a parity-corrected nearest translate in each D4 block and independent nearest translates in the tail. For primitivity, an extra period must send a fixed motif point to another listed point modulo the displayed lattice. The verifier tests all such shifts exactly and finds only the identity.

For a practical donor search with the four mobile sites kept: test the fixed centers first. One candidate can coexist with each slider if and only if the squared wrapped distance with that slider's free coordinate dropped is at least 3, because at most 1 can be supplied by the period-2 axis. Several candidates reduce to independent coverage tests on the four circles: a candidate with projected squared distance (b^2<4) forbids an open arc of radius (sqrt{4-b^2}) around its axis coordinate. Each slider can be repositioned precisely when that slider's arcs do not cover the whole circle.

One local caution: the verifier also detects pure coordinate contact pairs. In a head block, +2 and -2 along that axis arise from the same pair modulo the period lattice; in the tail they arise from a site and its period image. Adding the two linearized distance inequalities cancels any motif motions and forces the corresponding metric derivative diagonal to be nonnegative. All eleven are covered, ruling out strictly negative first-order volume derivative even when allowing joint motif shifts. This does not exclude second-order improvement or a different packing.
