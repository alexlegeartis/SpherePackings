# Constructive E6 packet scout

The 57-label all-good quotient code is a new literal aperiodic specimen
in the tested outputs, not a density or cardinality record. It gives
513 full-packet sites; the established 63-label, 567-site rank-two-period
construction is denser, and improving Coxeter–Todd needs 923 sites.
Exact enumeration shows the 57-label code has no nonidentity
translation and no additional individually compatible label. Thus it
is not merely a puncture of the 63-label periodic code. The verifier
checks every label-pair constraint and every possible added label.
No larger saturated aperiodic code was produced in these runs.

The successful aperiodic specimen came from a multiscale Witt
coordinate search. For 14 choices of complementary hyperbolic
directions, partition the two factors by their hyperbolic-plane
coordinates. Holding the outside labels fixed leaves a residual
rank-three product graph in each joint cell; reproducibly clear
groups of occupied cells and regrow those residual cliques. The
best unconstrained cardinality remained 63. Other constructive
tracks tested nine matched covector fibres (exact matching in each
one, disturbing the nine-way target permutation), multi-orientation
line bundles, and unions of affine-reflected copies of the 63 witness.
The two-parent union calculation used exact bipartite matching; no
checked two-parent or larger donor-atlas chart yielded a gain.
